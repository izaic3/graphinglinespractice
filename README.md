# Graphing Lines Practice

A self-contained webpage for students to practice graphing:

- Vertical lines (`x = a`)
- Horizontal lines (`y = b`)
- `y = x`
- `y = -x`

## Use

Download `index.html` and open it in a modern browser. No installation, build step, account, or internet connection is required for local use.

Students plot two points and check their line. All four line types appear in mixed practice, with each type included once per shuffled group of four. Hints, answer reveal, mouse/touch and keyboard input, and coordinate entry are included.

The layout prioritizes a large graph and readable feedback on small Chromebook screens. Solved, First try, and Streak counters are visible above the equation. Progress lasts for the current session.
